# 班级魔方立即执行与魔方日志设计

## 目标

修复班级魔方任务“立即执行”无可见反应的问题，对照 `D:\下载\BJMF-main` 统一远端接口用法，并将班级魔方运行记录和技术日志拆分为两个独立二级页面。

## BJMF 接口审计

### 保持现状

- 扫码入口使用 `https://bjmf.k8n.cn/weixin/qrlogin/student`。
- 扫码轮询使用 `?op=checklogin`。
- 登录回调参数固定交给 `https://bj.k8n.cn/student/uidlogin` 换取学生 Cookie。
- Cookie 名称使用动态 `remember_student_*` 识别，比参考项目硬编码名称更兼容。
- 二维码、GPS、GPS 加拍照和密码签到继续使用当前结构化表单解析与主机白名单校验。
- 未知远端响应继续标记为“结果未知”，不采用参考项目“HTTP 200 即成功”的宽松判断。

### 修正差异

- 学生和课程入口改为 `https://bjmf.k8n.cn/student`。
- 每次读取课程或签到项前先访问 `https://bjmf.k8n.cn/student/my` 预热会话。
- 签到列表使用：
  - `https://bjmf.k8n.cn/student/course/{course_id}/punchs`
  - `https://bjmf.k8n.cn/student/course/{course_id}/daka`
- 签到详情和提交继续使用：
  - `https://bjmf.k8n.cn/student/{punch_type}/course/{course_id}/{item_id}`
- 签到项同时通过 `punchcard_{id}`、详情链接和直接重定向页面识别，与参考项目的三种发现策略一致。
- 结果补齐“签到成功、已签到、未开始、当前无签到、登录失效、参数不足、结果未知、请求失败”状态。

## 立即执行

- 自动定时任务继续由后台调度器和有限线程池执行。
- “立即执行”改为独立同步服务方法，不再只返回是否加入线程池。
- 前端请求超时设置为 60 秒，点击后该行按钮显示加载状态并禁止重复点击。
- 接口返回本次执行汇总：
  - 任务 ID 与任务名。
  - 扫描到的签到项数量。
  - 成功、已签到、跳过、失败和结果未知数量。
  - 每个签到项的标题、模式、状态和中文消息。
- 即使没有找到签到项，也返回明确的“当前课程没有可执行签到项”，写入运行记录和魔方日志。
- 任务禁用不阻止管理员或任务所有者手动立即执行；自动调度仍只执行启用任务。
- 同一任务已有自动或手动执行进行中时拒绝重复执行，并返回明确提示。

## 运行记录

- `/class-cube/runs` 只展示 MySQL 中的结构化执行记录。
- 删除该页面底部现有的内存日志区域及其三秒轮询。
- 每次立即或自动执行至少产生一条结构化记录；没有签到项和执行前失败使用任务级记录，关联签到项允许为空。
- 保留筛选、刷新和未知结果重试功能。
- 运行记录保存业务结果，不用于展示 Python 异常堆栈或内部诊断信息。

## 魔方日志

- 新增二级菜单“魔方日志”，路由为 `/class-cube/logs`，排列在“运行记录”后。
- 新增独立页面 `ClassCubeLogs.vue`，视觉和交互仿照小小签到 `Logs.vue`：
  - 日志级别筛选。
  - 当前条数。
  - 手动刷新。
  - 滚动到底部。
  - 深色等宽字体日志面板。
  - 移动端自适应。
- 页面使用现有 `/api/class-cube/logs`，不得读取 `/api/xxqd/logs`。
- 班级魔方 logger 同时写入内存缓冲和 `backend/logs/class_cube.log`。
- 日志格式统一为 `YYYY-MM-DD HH:mm:ss,SSS [LEVEL] message`。
- 文件按天轮转，保留 7 天；日志不得包含 Cookie、密码、Webhook 或完整远端响应。
- 应用重启后接口从日志文件尾部恢复最近记录，页面不因重启变空。

## 日志内容

每次执行至少记录：

- 任务开始：任务 ID、任务名、账号显示名、课程名、触发来源。
- 会话预热结果。
- `punchs` 和 `daka` 列表获取结果及识别数量。
- 每个签到项开始和最终业务状态。
- 无签到项、任务禁用、登录失效和远端异常。
- 企业微信通知成功或失败。
- 任务结束汇总与耗时。

只记录业务标识和异常类型，不记录认证信息或敏感参数。

## 并发与错误处理

- 自动和手动执行共享同一个任务级运行锁。
- 远端请求超时或失败时，接口返回可读中文错误，后台记录异常类型。
- 一个签到模块列表获取失败时继续尝试另一个模块；两个模块都失败才判定任务失败。
- 企业微信通知失败不覆盖签到结果。
- 前端始终结束按钮加载状态，并在成功、无签到或失败时给出不同提示。
