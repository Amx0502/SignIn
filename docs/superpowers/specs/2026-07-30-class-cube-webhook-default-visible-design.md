# 班级魔方企微机器人地址默认显示设计

## 目标

管理员进入“班级魔方 → 系统概览”时，企业微信机器人 Webhook 以明文显示，便于直接查看和编辑。

## 设计

- 将 `ClassCubeOverview.vue` 中 Webhook 输入框的类型由 `password` 改为 `text`。
- 移除 `show-password` 属性，不再显示眼睛图标，也不提供隐藏切换。
- 保留现有数据加载、编辑、校验与保存流程。
- 保留现有权限边界：只有管理员能获取和编辑完整 Webhook，非管理员只看到是否已配置。
- 保留现有日志脱敏规则，Webhook Key 不得写入日志。

## 验证

- 静态检查输入框使用 `type="text"`，且不再包含 `show-password`。
- 构建前端，确认模板可正常编译。
- 确认设置接口、后端校验和日志脱敏代码没有改动。
