# 班级魔方任务填写与企业微信通知设计

## 目标

将班级魔方自动任务改为 BJMF-main 的填写和定时执行方式，并用独立的企业微信机器人通知替换微信 Server 酱、QQ/Qmsg 通知。班级魔方与小小签到的配置、调度、日志和通知保持隔离。

## 配置

- 在现有 `backend/settings.json` 中增加 `class_cube_webhook_url`。
- `webhook_url` 继续供小小签到使用，`class_cube_webhook_url` 只供班级魔方使用。
- 班级魔方“系统概览”负责读取、校验和保存企业微信机器人 Webhook。
- Webhook 为空时跳过通知，不影响任务执行。

## 自动任务填写

- 账号：从已扫码登录并保存到 MySQL 的班级魔方账号中选择。
- 姓名和班级：选择账号后自动展示，不要求用户重复输入。
- 课程：从该账号已同步的课程中选择。
- 位置：经纬度合并为一个文本输入框，兼容空格、英文逗号、中文逗号、竖线和连续混合分隔符；解析后分别保存纬度、经度和精度。
- 坐标拾取：按钮使用新标签页打开 `https://www.lddgo.net/convert/position`，用户复制坐标返回填写；系统不调用或读取第三方网站接口。
- 执行时间：一个任务支持多个每日时间点，格式为 `HH:mm:ss`；可增加、删除并去重。
- 日期范围：开始日期和结束日期均可留空。只填写开始日期表示从该日开始长期执行；只填写结束日期表示执行到该日结束；同时填写时开始日期不得晚于结束日期。
- 签到参数：保留定位精度、照片和密码，用于 GPS、GPS 加拍照、密码等签到方式。
- 通知：任务只提供“发送企业微信通知”开关，不显示 Webhook、微信 Server 酱或 QQ/Qmsg Key。

## 数据模型与兼容

`class_cube_tasks` 增加：

- `schedule_times`：每日执行时间点列表，使用 JSON 文本保存。
- `start_date`：可空开始日期。
- `end_date`：可空结束日期。
- `notify_wecom`：是否发送企业微信机器人通知。
- `last_schedule_key`：最近一次成功认领的日期和时间点，用于防止同一时间点重复执行。

应用启动时按现有数据库兼容机制补充缺失列。已有任务默认保留启用状态，通知默认开启；没有执行时间的旧任务不自动执行，必须由用户补充时间点，避免升级后意外签到。

## 调度与执行

调度器按较短固定间隔检查启用任务，但只有满足以下条件才认领执行：

1. 当前日期位于任务日期范围内。
2. 当前时间已到达某个配置时间点。
3. 该日期和时间点尚未被当前任务认领。
4. 任务未被其他工作线程占用。

认领采用数据库条件更新，保证多线程或多进程情况下同一时间点不会重复执行。任务执行时从指定课程同步并获取当前可签到项目，再按项目类型提交二维码、GPS、GPS 加拍照或密码签到所需参数。

手动“立即执行”不受日期范围和时间点限制，但仍使用相同的课程同步、签到和通知流程。

## 企业微信机器人通知

- 使用 `class_cube_webhook_url` 向企业微信机器人发送文本或 Markdown 消息。
- 消息包含任务名、账号、课程、签到项目、执行时间、成功或失败状态及简短原因。
- 每次任务执行生成一条汇总通知，避免同一课程多个签到项产生大量独立消息。
- HTTP 超时、非成功状态码或企业微信返回错误时写入班级魔方运行记录和 `/api/class-cube/logs`，但不改变已经完成的签到结果。
- 删除班级魔方范围内的 Server 酱、Qmsg 字段、请求和界面代码；不改动小小签到已有的企业微信通知实现。

## API 与界面

- 班级魔方设置接口返回和更新 `class_cube_webhook_url`，普通用户只能读取是否已配置，管理员可查看和修改完整地址。
- 任务创建和更新接口接收 `schedule_times`、`start_date`、`end_date`、`notify_wecom`。
- 任务返回值包含上述调度字段，Webhook 不随任务数据返回。
- 班级魔方系统概览展示通知配置状态和 Webhook 设置。
- 自动任务编辑器采用分区表单：账号与课程、位置、签到参数、执行计划、通知与启用状态。

## 校验与错误处理

- 坐标必须是两个有限数字，纬度范围为 `-90..90`，经度范围为 `-180..180`。
- 时间必须符合 `HH:mm:ss`，保存前排序并去重，至少保留一个执行时间点。
- 日期范围错误时前后端都拒绝保存。
- 企业微信 Webhook 必须使用 HTTPS 且主机为 `qyapi.weixin.qq.com`。
- 配置或通知失败显示明确中文错误，并写入班级魔方独立日志。

## 测试

- 坐标分隔格式、范围和非法输入测试。
- 多时间点排序、去重和格式校验测试。
- 开始和结束日期组合测试。
- 数据库旧表补列及旧任务不自动执行测试。
- 同一任务和时间点仅认领一次的并发测试。
- 手动执行绕过时间限制测试。
- 企业微信 Webhook 主机校验、成功、超时和远端错误测试。
- 小小签到与班级魔方配置和日志隔离测试。
- 前端表单、坐标拾取链接、通知字段移除和生产构建验证。
